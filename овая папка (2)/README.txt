entry-level SIEM - учебный проект на Python для анализа сетевых логов, выявления потенциально подозрительной активности и формирования предупреждений по IP-адресам. Проект находится на раннем
этапе разработки.
Сейчас основное внимание уделяется обработке сетевых событий, извлечению признаков активности и разработке логики обнаружения.
Возможности:
1 Парсинг логов. чтение текстовых файлов и преобразование записей в структурированные события.

2 Анализ времени. сортировка событий по времени и подсчёт максимального количества событий одного источника в скользящем 60-секундном интервале.

3 Анализ соединений. подсчёт событий и определение уникальных IP-адресов назначения для каждого источника.

4 Определение сервисов. сопоставление известных портов и протоколов с SSH, HTTP, HTTPS, DNS, SMTP, POP3, IMAP, RDP и SMB.

5 Система предупреждений. обнаружение высокой активности, большого количества уникальных адресов назначения и событий с неизвестным сервисом.

6 Оценка риска. предварительная оценка на основе суммы баллов за обнаруженные признаки.

7 Текстовый отчёт. вывод предупреждений, связанных сетевых событий и уровня риска для каждого IP-адреса.

Технологии:
Python
datetime — обработка временных меток
Стандартные структуры данных Python: списки, словари и множества
Внешние библиотеки пока не используются.

Формат входных данных:
На текущем этапе программа ожидает текстовый файл, в котором каждая запись содержит семь полей, разделённых пробелами:
date time source destination protocol port event_type

Пример:
2026-10-02 10:15:00 10.0.1.10 192.168.1.1 TCP 445 SMB
2026-10-02 10:15:10 10.0.1.10 93.184.216.34 UDP 53 DNS_QUERY
2026-10-02 10:15:20 10.0.1.15 172.16.10.5 UDP 30 UNKNOWN_SERVICE

Это упрощённый формат для тестирования. Программа пока не предназначена для непосредственного анализа произвольных файлов журналов реальных сетевых устройств, как работает анализ.Программа читает 
файл и преобразует записи в структурированные события. События сортируются по времени. Для каждого источника анализируется частота событий в пределах 60 секунд. Определяются известные сервисы по 
сочетанию порта и протокола. Вычисляются дополнительные признаки активности. Формируются предупреждения и рассчитывается предварительный уровень риска. Результаты выводятся в текстовом отчёте.

Ограничения текущей версии:

Правила обнаружения пока простые и дают ложные срабатывания.
Неизвестный сервис сам по себе не означает наличие атаки.
Высокая активность и большое количество адресов назначения не доказывают вредоносное поведение.
Пороговые значения и веса пока предварительные.
Обработка логов рассчитана на небольшой объём тестовых данных.
Программа пока не использует машинное обучение и не подтверждает наличие атак.

Планы развития:
Разработка сценариев обнаружения на основе сочетаний сетевых признаков.
Формирование гипотез с объяснением оснований и ограничений.
Улучшение структуры кода и обработки ошибок входных данных.
Создание набора тестовых логов для проверки обнаружения и ложных срабатываний.
Оптимизация анализа временных интервалов.
Изучение возможностей интеграции методов машинного обучения.

Статус проекта раняя разработка.
Моя программа разрабатывается в образовательных целях как способ изучить Python, анализ сетевых событий и принципы построения систем обнаружения потенциальных угроз.
Проект не является заменой профессиональных средств мониторинга и информационной безопасности.

Для работы необходимо ввести название файла.txt, информация которого соответсвует date time source destination protocol port event_type
